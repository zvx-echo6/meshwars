  2. Enter a display name in the box below.

  5. Click Join.

  6. Copy your API key now — this is the only time it will ever be shown.

    Closing or reloading this page loses it for good. MeshWars stores only a one-way hash of your key, never the key itself, so there is no way for anyone, including an admin, to look it back up. The only fix for a lost key is a brand new one from an admin, which retires this one. Copy it somewhere safe before you do anything else.

    Your key will appear here once you join.

  7. Open MeshMapper, then Settings, then scroll to API Endpoints.

  8. Toggle Custom API Endpoint on.

  9. Paste this as the URL.

    Do not paste the meshmapper:// link into the URL field. It is not a web address. It is only for Import from Clipboard.

  10. Paste your API key into the API Key field.

    Your key will appear here once you join.

  11. Save.

  12. In the same API section, make sure Include Contact Key is on.

  13. Start a wardriving session — nothing is sent without one.

  14. Find your node ID in the Meshtastic app — it looks like !a1b2c3d4.

  15. Paste your key into the box at the bottom of this page (under Check your setup) and add that node ID. You can add as many radios as you like, any time.

  16. In the Meshtastic app, under Radio Configuration → LoRa, turn on OK to MQTT. Without it no gateway will forward your packets and MeshWars will never see you.

  17. Under Radio Configuration → Position, make sure GPS is enabled and your node is broadcasting its position.

  18. Under Channels, on your primary channel, set position precision to full. If it is reduced, your position gets rounded off and you will paint the wrong square, or none at all.

  19. Make sure you are on FREQ51, so a gateway that feeds meshview can actually hear you.

How do I know it's working?

MeshMapper sends a batch every fifteen to thirty seconds while a wardriving session is running. Nothing is sent between sessions.

Squares are only claimed where your radio hears a repeater. Driving through an area with no mesh coverage logs your position and claims nothing — that is normal, not a fault.

To check, paste your API key into the setup check at the bottom of this page. It will tell you when MeshWars last heard from you and what is wrong if anything is.

Nothing is pushed to MeshWars at all. MeshWars polls meshview every 45 seconds and picks you up whenever your node broadcasts a position that a feeder hears — there is no session to start or batch to send.

Squares are only claimed where a feeder hears your node's position. If you're somewhere with no feeder coverage, your position is never reported to meshview in the first place, so nothing gets claimed — that is normal, not a fault.

To check, paste your API key into the setup check at the bottom of this page. It will tell you when MeshWars last picked up your node from meshview, how many squares you hold, and what is wrong if anything is.
