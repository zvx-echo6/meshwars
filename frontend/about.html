What the game is

Players are on one of seven teams. The map is divided into squares roughly 300 metres across. You claim a square for your team by being in it and hearing the mesh from it. Teams take squares from each other. The team holding the most squares when a season ends wins.

The seven teams
RED GREEN BLUE PURPLE YELLOW ORANGE PINK

Every player picks one of these seven colours, and every team competes for the same ground.

How scoring works
  1. You claim a square by hearing repeaters from it. Each repeater a ping hears is worth a tenth of a point, up to one point per ping.
  2. A ping that hears no repeaters scores nothing and claims nothing. Being somewhere is not enough — you have to reach the mesh.
  3. The first team to paint an unclaimed square takes it.
  4. A square that has just been captured cannot be taken for fifteen minutes, no matter what.
  5. After that it falls to whoever out-scores the team currently holding it. Only the holder's score matters, not every other team's.
  6. The first time a new person paints a square for their team, it is worth an extra half point. More people beats one person going back and forth.
  7. The same person cannot repaint the same square within five minutes.
  8. Scores fade over time, so held ground has to be revisited.

How to join
  1. Get the invite code from whoever invited you.
  2. Register at /join, pick a name and a team colour.
  3. Save the API key you are given. It is shown once.
  4. Connect MeshMapper:
    1. Open MeshMapper
    2. Open Settings
    3. Scroll down to API Endpoints
    4. Toggle Custom API Endpoint on
    5. URL: https://meshwars.com/api/mc/ingest
    6. API Key: your key
    7. Save
    8. Make sure Include Contact Key is on
    9. Start a wardriving session — nothing is sent without one
    Do not paste the meshmapper:// link into the URL field. It is not a web address. It is only for Import from Clipboard.
  5. Start a wardriving session and drive.

This does not replace MeshMapper — your standing there is unaffected.

You need an active wardriving session running for anything to be sent.

"Include Contact Key" must stay on.
