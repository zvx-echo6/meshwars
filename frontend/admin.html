Accounts

About accounts

Every account, not just the ones with a linked player. An account with no linked player is reached from here only — released by "Release account link" on a player above, or never claimed after signing in. Deleting an account removes it and its sign-in identities and sessions; if a player is linked, that player is tombstoned exactly the way "Delete player" leaves it. Disable two-factor, clear password, and remove a sign-in method are recovery actions, not deletion — each only clears a credential so the account's holder can get back in through whatever they still have; none of them lets an operator sign in as the account, and each is offered only when the account actually has that credential to clear.

An account's role, if any, shows as a badge on its row, with Grant admin or Revoke alongside it — operator-only, both here and on the server, so an admin's own session never even sees the controls. Granting always mints admin; becoming an operator has exactly one door, claimed on the account page with the admin token and an active two-factor code, never a grant from this panel.

Nets

About nets

Every weekly net the poller watches, on either board, plus the settings that apply to all of them at once. Nets are found differently depending on their connector kind — a MeshCore net (CoreScope or Beacon) is scoped to one channel on its connector, a Meshtastic net (Meshview or MQTT) is found by its hashtag appearing in a message on any channel — so the form below shows different fields per connector kind rather than one merged form. MQTT is a live broker subscription rather than a poll, so a broker outage shows up here as a poll error just like any other connector.

Settings below apply to every net at once, read fresh on the poller's next cycle — no restart.

Paint

About paint

Which source paints the Meshtastic board, plus FreqMapper's own connector and scoring. Meshview, FreqMapper, or both can paint at once — when both are selected, each paints independently and the board's existing capture cooldowns handle a cell either one touches, same as they do for any two players. Meshview keeps providing node names and roster either way. Read fresh by both pollers on their next cycle — no restart.

Meshtastic paint source

About paint source

Meshview paints from the position packets it already polls. FreqMapper paints from independently-verified reception events instead — it reports no per-event station count, so its scoring below is a flat award rather than a per-station one. Both is the default: both painters run, unconditionally, with no priority between them. Switching this changes where live Meshtastic territory comes from; saving asks you to confirm which source you are switching to.

FreqMapper connector

Blank blocks every FreqMapper event — FreqMapper's feed hands back history on every request, so a blank date is what stops a freshly enabled connector from repainting the board with everything the feed can still reach in one pass. Setting this to today starts painting forward from now; it does not backfill the feed's history.

Scoring

FreqMapper reports no per-event station count, which is why this is a flat award per event rather than a per-station one.

Status

Clearing the cursor makes the next poll re-walk FreqMapper's feed from the beginning — useful when the upstream moves to a new host and the stored cursor no longer resolves against it. Safe to do at any time: every event this deployment has already processed is remembered by its own id, so events already seen are skipped again on the re-walk, never double-scored.

Tile release

About tile release

Releases a cell once its owning team's score has decayed to exactly 0 and stayed there longer than the window below — there is no neutral/zero-owner state, so the tile is deleted and becomes recapturable by anyone. Dry run only logs what a sweep would release each cycle; nothing is actually deleted until it's off. The window has a 168-hour (7-day) floor enforced on the server no matter what is typed below.

Turning dry run off is what makes the sweep start deleting rows. Saving with it off asks you to confirm the exact count shown in the projection below.

Projection

What the window above would release right now, and each team's share of its own board — read-only. Refresh after changing the window or after time passes.

Months

About months

Months close on their own from ordinary traffic. Use this only to recompute one that closed while history was wrong, or to close one the service was down for. A month still being played is refused.

Places

About places

Previews the weekly rotation draw for Places Worth Going — landmarks and small parks, deterministic from the week alone. This does not persist anything; the real draw for the current week resolves itself the first time a scoring ping or the map needs it. Leave the week blank for the current week, or give any date and it snaps to that date's Wednesday.

Notice

About notice

A one-time message shown to players on their first map load. Plain text only — line breaks are kept, nothing else is. A player who dismisses it never sees it again unless the version key below changes; bumping the key re-shows it to everyone, including anyone who already dismissed the last one. History lives in the repo's CHANGELOG, not here — saving replaces whatever notice was here before.

Discord

About Discord announcements

Posts end-of-month honors, season closes, a Sunday weekly recap, a wrap-up the day after each net -- and, on request, a one-off test message -- to a Discord channel via a webhook. The webhook URL is a secret and is never shown here once saved; leave it blank when saving other fields to keep the one already configured. Each "Announce ..." toggle below gates only its own kind -- it can be turned off while leaving the webhook enabled, so the test button and every other kind still work.

Team emoji: comma-separated TEAM=token entries, one per team, using exactly the token Discord itself echoes back for a custom emoji (e.g. <:mw_red:123456789>). A team left out of this list renders with no dot, exactly as if none were configured.

Channel routing

Send a specific announcement kind to its own Discord channel instead of the default one above. A kind with no route here uses the default webhook; a route left "Off" is never announced at all -- it does NOT fall back to the default.

Team roles

About team roles

A separate feature from the announcements above: "Herald," a Discord bot, gives a player's linked Discord account the role for their MeshWars team (and no other team's role) once they're both linked and a member of the server. The bot token is a secret, set only via the DISCORD_BOT_TOKEN environment variable -- never entered here.

Enabled/Guild ID are saved together with the Save button above -- they're part of the same form.

Team channels

About team channels

A private text channel per team, inside one shared category, visible only to players holding that team's role (and Herald itself). Layered on top of team roles above -- needs roles enabled, a bot token, and a guild ID before it can do anything.

Saved together with the Save button above -- part of the same form as everything else on this page.

About slash commands

A FOURTH, separate Discord integration: /me, /standings, /honors, /nextnet, and /player, answered by an HTTPS endpoint (no bot gateway connection). Leaderboard

About the leaderboard

A FIFTH, separate feature: one pinned message per deployment, posted once through the webhook routed for kind "leaderboard" above (or the default webhook, same fallback as every other kind) and then edited in place -- never reposted -- whenever the standings actually change. Pinning uses Herald (the same bot as team roles above); a missing bot token or "Pin Messages" permission still lets the message keep updating, it just won't be pinned. Shows, per board with an active season: team standings, then the top players from the site's own Wardrivers/NetOps/Explorer rankings.

Saved together with the Save button above -- part of the same form as everything else on this page.
