Players

Check-ins

Credit a check-in somebody earned but did not receive. Points and streak are worked out exactly as the poller would have on the night, so it is worth what it should be — the monthly honors read these rows and cannot tell it was added by hand.

Seasons

Changing the season length in config only affects the next season. This changes the one being played.

Months

Months close on their own from ordinary traffic. Use this only to recompute one that closed while history was wrong, or to close one the service was down for. A month still being played is refused.

Places

Previews the weekly rotation draw for Places Worth Going — landmarks and small parks, deterministic from the week alone. This does not persist anything; the real draw for the current week resolves itself the first time a scoring ping or the map needs it. Leave the week blank for the current week, or give any date and it snaps to that date's Wednesday.

API keys

Keys for the public read API at /api/v1 — one per integration, so a misbehaving bot can be revoked on its own. Read-only: these cannot post wardriving data.
